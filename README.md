# MaxxDev — maxxdev.ru

Сайт разработчика MaxxDev на Vue 3 + Vite. Чёрный фон, оранжевые акценты, адаптивная верстка и эффекты с поддержкой `prefers-reduced-motion`.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run serve
```

## Сборка

```bash
npm run build
```

Готовые статические файлы находятся в `dist/`. Их можно разместить на обычном статическом хостинге. Дополнительный сервер для этой версии не требуется.

## Где менять содержание

- `src/content.js` — имя, контакт, ссылки, кейсы и услуги.
- `src/App.vue` — разделы и поведение интерфейса.
- `src/style.css` — цвета, верстка и эффекты.
- `index.html` — заголовок и метаданные страницы.

## Заявки

Пока публичный контакт не предоставлен, форма скачивает или копирует бриф. Она **не отправляет** данные на сервер и не показывает ложное подтверждение отправки. Черновик хранится только в браузере посетителя, чтобы он мог вернуться к заполнению.

Добавьте реальный бизнес-email в `profile.email` в `src/content.js`. После этого появятся почтовая ссылка и действие «Открыть в почте»: письмо откроется в почтовом приложении посетителя, который сам подтвердит отправку. Для автоматического приёма заявок нужен отдельный backend или сервис форм. Не добавляйте пароли и SMTP-данные в клиентский код.

Перед публичным запуском проверьте актуальность описаний проектов и добавьте реальные скриншоты вместо декоративных иллюстраций. Отзывы, количественные результаты и цены в сайт не добавлены, поскольку они не были предоставлены.

## Что уже работает

- Адаптивная навигация и мобильное меню.
- Фильтр портфолио по платформе.
- Подробные кейсы в нативных диалогах с закрытием по Escape.
- Переход от услуги к брифу с выбранным типом проекта.
- Проверка обязательных полей, сохранение черновика, копирование и скачивание брифа.
- Параллакс на первом экране, эффекты карточек, появление разделов при прокрутке.
- Ограничение движения при системной настройке уменьшенной анимации.

## Структура проекта

Стартовый шаблон Vue CLI заменён на Vite. Команда `npm run serve` сохранена; также доступны `npm run dev` и `npm run build`. Node.js: 20.19+ или 22.12+.
